# Roberto Mazza — Portfolio

The source code of my personal portfolio, a single-page site built with **React** and **Vite**.
It collects who I am, the work experience I've built up as a mobile and web developer, and the
quickest ways to get in touch.

## 🌐 Live Site

[robertomazza.dev](https://portfolio-git-main-rob-bad5.vercel.app)

---

## 🧰 Tech Stack

- **Library:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Build tool:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Hosting:** [Vercel](https://vercel.com/)

---

## 🚀 Run it locally

```sh
npm install
npm run dev      # http://localhost:5173
```
